## 2026-05-08 - [Missing Form Control Bindings]
**Learning:** Found an accessibility anti-pattern in the application's forms where `<label>` elements were visually indicating input purposes but were not programmatically associated with `<input>` elements using `htmlFor` and `id` attributes. This prevents screen readers from understanding the connection and prevents users from clicking labels to focus inputs.
**Action:** Always ensure that every `<label>` element has an `htmlFor` attribute that explicitly matches the `id` of its corresponding form input (`<input>`, `<select>`, `<textarea>`).
## 2024-05-18 - Replacing interactive divs with buttons for keyboard navigability
**Learning:** In `manage/page.tsx`, the project expand/collapse functionality was implemented using a `<div>` with an `onClick` handler. This makes the toggle completely inaccessible via keyboard navigation (e.g., Tab key) and lacks semantic meaning for screen readers. Using existing Tailwind CSS classes (`focus-visible:ring-2 focus-visible:ring-blue-500`) applied to a `<button>` provides the correct focus states out of the box, avoiding the need for custom CSS while making the interaction fully accessible.
**Action:** Always use `<button type="button">` for non-submitting interactive elements that trigger on-page actions (like expanding/collapsing sections). Ensure they have explicit `aria-expanded` and `aria-controls` properties for screen reader context, and proper `focus-visible` styling for keyboard navigators. Never use interactive `<div>` elements without the proper semantic attributes, but prefer semantic `<button>` instead.
## 2024-05-28 - [Accessible Grid Cell Inputs]
**Learning:** Custom spreadsheet-like grids often have inputs without visual labels. These inputs are inaccessible to screen readers because they lack context (row/column headers).
**Action:** When building custom grid or spreadsheet components, always include a visually hidden (`sr-only`) `<label>` tied to a unique `id` for every cell's input field. Populate the label dynamically with row/column contextual metadata to ensure screen reader accessibility.
